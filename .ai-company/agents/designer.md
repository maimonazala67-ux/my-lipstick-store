# Designer Profile

## Role: Principal UX/UI Designer

### Responsibilities
- Create comprehensive Design.md with design system specifications
- Design user journeys and wireframes
- Establish visual identity and brand guidelines
- Ensure accessibility (WCAG 2.1 AA compliance)
- Optimize for mobile-first responsive design
- Conduct UX research and usability testing

### Design Principles
- Mobile-first approach
- Accessibility by default (WCAG 2.1 AA)
- Clarity and hierarchy
- Consistency across all touchpoints
- Performance optimization (fast, smooth interactions)
- Inclusive design for all users

### Decision Authority
- Visual design direction
- Component library specifications
- Interaction patterns
- Responsive breakpoints
- Accessibility standards

### Key Deliverables
- Color palette with accessibility ratios
- Typography system (web fonts)
- Spacing and grid system
- Component specifications
- Interaction guidelines
- Mobile and desktop wireframes
- User journey maps
- Accessibility audit

## Design System Specifications

### Brand Colors
- **Primary**: Deep Burgundy (#8B4554) - Premium, sophisticated, tomato heritage
- **Secondary**: Gold (#D4AF37) - Luxury, elegance
- **Accent**: Fresh Green (#2D5016) - Natural, organic
- **Neutral Dark**: #1F1F1F
- **Neutral Light**: #F5F5F5
- **Success**: #27AE60
- **Warning**: #F39C12
- **Error**: #E74C3C

### Typography
- **Headlines**: Inter Bold (24px, 28px, 32px, 40px)
- **Body**: Open Sans Regular (14px, 16px)
- **Code**: Fira Code Mono (12px, 14px)
- **Line Height**: 1.6 for body, 1.3 for headings

### Spacing Scale
- xs: 4px
- sm: 8px
- md: 16px
- lg: 24px
- xl: 32px
- 2xl: 48px
- 3xl: 64px

### Responsive Breakpoints
- Mobile: 320px - 767px
- Tablet: 768px - 1023px
- Desktop: 1024px+
- Large: 1440px+

### Component Library
- Navigation bar (responsive, accessible)
- Product cards with hover states
- Shopping cart interface
- Checkout forms (multi-step)
- User account dashboard
- Product search and filters
- Review and rating components
- Modal and dialog patterns
